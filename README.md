# Kerala Gold Rate (22 Ct)

Web app showing today’s and yesterday’s 22 Ct gold rate in Kerala, a 6-month price chart, 1 Pavan price,
a jewellery price calculator (editable weight, making charge and GST) and a “what can my cash buy” tool.

- Frontend: HTML, CSS, vanilla JavaScript (no build step)
- Data: GitHub Actions collects the rate daily into `data/rates.json`
- Hosting: GitHub Pages · Android: planned via PWA/Capacitor
